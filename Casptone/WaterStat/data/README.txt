No dataset is bundled and none is required: WaterStat starts empty and you upload a CSV or Excel file in "Dataset Assessment".
Optional: if you place a file named water_quality.csv in this folder it is auto-loaded (and validated) at startup;
an upload always replaces it.
Required columns: pH (or ph), Hardness, Solids, Chloramines, Sulfate, Conductivity, Organic_carbon,
Trihalomethanes, Turbidity. Potability (0/1) is needed for group tests and modeling.
